# 第一阶段业务边界

## 目标

在本地受控环境形成可重复验收的闭环：任务输入 → 资源与规则建模 → 校验 → 确定性规划 → 风险评估 → 方案对比/重规划 → 人工采纳 → 报告与留痕。

## 保留能力

| 能力 | 第一阶段可执行基线 |
| --- | --- |
| 项目与任务输入 | 创建项目；生成样例或导入任务单元、装备组和频谱规则 Excel；提供模板与参数库。 |
| 频谱规则 | 维护可用、禁用、保护、固定占用等规则；规则变更可追溯。 |
| 输入校验 | 规划前返回错误、警告、缺失问题和摘要；不完整输入不得伪装成成功方案。 |
| 自动规划 | 由确定性规划器按目标、权重和策略模板生成方案，并返回运行编号、状态和摘要。 |
| 风险与可视化 | 展示保障矩阵、频段占用、空间关联、同频/邻频风险、瓶颈、替代资源和解释链。 |
| 多方案决策 | 批量比较目标与约束，展示指标、取舍、推荐候选、角色视角和采用护栏。 |
| 动态重规划 | 支持频段增禁、优先级/满足率调整、任务或装备锁定、避让/强制频段；先预览/试算，确认后执行。 |
| 交付与留痕 | 导出 HTML 报告和 Excel；保留规划版本、重规划效果、审计日志和能力清单。 |
| 验收辅助 | 保留性能压测、容量分批和跨批风险闭环，用于边界验证；不作为普通用户的必经流程。 |

`frontend/` 是上述能力的唯一业务验收入口。后端保留的旧台站级接口仅作兼容，不新增第一阶段产品承诺。

## 暂缓能力

- 生产级登录、细粒度授权、多人协同审批、租户隔离和电子签批。
- 接入真实指挥系统、传感器、频谱监测流、地图底图或设备控制链路。
- 自动下发频率、无人值守重规划、智能模型自主修改规则或批准方案。
- 公网/云端生产部署，以及涉密、敏感或未经脱敏数据处理。
- 对实际电磁环境的实时性、全局最优、零干扰或任务成功作保证。
- 将 `battlefield-spectrum-site/` 接成业务后台、持久化真实项目或承担验收。
- 合并或淘汰旧台站级接口；在另行迁移决策前只维持兼容。

## 角色与决策权

| 角色 | 可以决定 | 不得单独决定 |
| --- | --- | --- |
| 任务负责人 | 任务目标、优先级、最低保障率、可接受降级 | 违反禁用/保护规则的采用 |
| 频谱筹划员 | 数据维护、规则草拟、发起校验/规划/预览/试算 | 未经复核直接发布高风险或变更方案 |
| 安全/合规复核员 | 规则合规、高风险处置、导出与外发边界；可否决 | 代替任务负责人改变任务优先级 |
| 授权指挥/业务负责人 | 在证据和复核意见基础上最终采纳、发布 | 要求系统绕过硬规则或审计 |
| 系统/优化器 | 按输入确定性计算、排序、记录证据 | 业务批准、责任认定、实装下发 |
| 智能助手/LLM | 解释结果、提出补充问题和建议 | 生成权威频率、修改事实数据、自动执行建议 |

第一阶段未实现技术性角色权限；每次实际使用必须由组织流程确认操作者身份和授权范围。

## 安全边界

1. 系统定位为规划决策辅助工具，不是作战控制系统或权威频率发布系统。
2. 当前 API 无认证授权，只能绑定受控本地网络并限制可信操作者；不得直接暴露到公网或不受信网络。
3. 只处理样例、仿真或获批脱敏数据。Sites 演示中的“脱敏”字样不构成安全证明。
4. 外部 LLM 默认关闭；启用时不得发送坐标、原始任务明细、敏感标识或未审查风险记录。
5. 禁用、保护和固定占用规则是硬边界。高风险、未满足装备组或约束变体必须显式展示并人工复核。
6. 导出物、数据库和审计记录按源数据保护；不得因生成摘要或图表而降低数据等级。

## 不可破坏的行为基线

后续变更必须同时满足：

1. **单一业务入口**：业务闭环继续由 `frontend/` 承担；演示面不得产生看似真实的权威结果。
2. **单一事实来源**：项目、规则、方案、风险、版本和审计以 `backend/` 返回及持久化数据为准。
3. **确定性分配**：频率和约束处理由确定性规划器完成；无 LLM 配置时完整闭环仍可运行。
4. **先校验后采纳**：错误必须阻断成功交付；警告、未满足项和高风险不得被隐藏或改写为“可交付”。
5. **结果可解释**：方案至少保留运行编号、目标/策略、关键指标、风险理由或解释链，以及可追溯输入上下文。
6. **重规划受控**：预览/试算不得改写当前方案；执行前必须展示变更项并取得人工确认，执行后生成新运行版本和审计记录。
7. **推荐非批准**：推荐排序必须同时展示关键取舍和护栏；不得自动采用推荐候选。
8. **历史不可冒充当前**：查看历史方案不得悄然覆盖当前方案；导出必须关联明确的项目与运行版本。
9. **演示不作证据**：`battlefield-spectrum-site/` 的静态指标、打印页和交互状态不得进入业务审计或验收结论。
10. **安全不降级**：不得以功能便利为由扩大网络暴露、向外部模型发送未脱敏数据或接入自动执行链路。

## 第一阶段验收门槛

- `GET /api/phase-one-capabilities` 保持九类核心能力为 `ready`，且每类有可调用端点。
- 端到端用例至少覆盖：创建项目、生成/导入数据、校验、规划、可视化风险、策略试算或对比、受控重规划、导出、版本审计。
- `frontend/` 构建成功，主流程能消费真实 API；演示面单独构建，其结果不得替代业务验收。
- 若变更触及安全边界、角色决策权或上述十条行为基线，必须先更新 ADR，再实施代码变更。
