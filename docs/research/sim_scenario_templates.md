# SIM战例任务模板

更新日期：2026-07-10

## 目的

本目录将公开战例中可核验的任务结构和失效模式转换为平台可加载的合成场景，用于验证任务筹划、智能分配、冲突评估和动态重筹。

- 公开资料只提供任务背景、系统关系和公开问题。
- 坐标、频率、带宽、功率、设备数量和保护距离全部是 `SIM-*` 合成值。
- 模板不复原行动频道、部署位置、网络初始化数据、电子战配置或交战规则。
- `spectrum_rules.xlsx` 中的规则来源统一为 `SIM_CASE_TEMPLATE`，不代表任何真实授权。

## 使用方式

### 平台内直接加载

四个场景已加入 `/api/task-scenarios`。在任务筹划页面选择场景后生成样例，会整体替换当前项目的任务单元、装备组和频谱规则。

### Excel导入

每个 `samples/sim_scenarios/<scenario_key>/` 目录包含：

1. `task_units.xlsx`
2. `equipment_groups.xlsx`
3. `spectrum_rules.xlsx`
4. `manifest.json`

三个Excel文件分别对应平台现有上传入口。导入顺序应为任务单元、装备组、频谱规则；开始导入前应创建独立仿真项目，避免覆盖正在使用的项目数据。

上传接口现在会拒绝缺少必需列或零记录的文件，因此研究基线工作簿不能被误当作频谱规则模板导入。

当前三个Excel入口分别提交数据，不构成一次原子导入；若导入中断，应重新按顺序导入三份文件并执行“任务校验”。需要一次性整体替换时，优先使用平台内的场景直接加载功能，该流程在单个事务中写入三类数据。

## 当前限制

当前场景表示任务开始时的静态快照。`manifest.json` 中的 `dynamic_events` 是下一步重筹注入清单，尚未作为独立的阶段和事件表持久化。

后续数据模型应增加：

- `scenario_phases`：阶段编号、时间窗、激活任务和退出条件。
- `scenario_events`：链路失效、传感器离线、节点加入、频段禁用和优先级变化。
- `task_dependencies`：任务前置关系、关键链路和失效影响。
- `simulation_assumptions`：区分公开事实、推导约束和合成参数。
